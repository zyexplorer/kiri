## New
- **Testcontainers.** Testcontainers runs against Kiri as it does against Docker: the version check passes, Ryuk cleans up, and databases such as MySQL become ready. `docker version` shows Kiri's own version as the Kiri component.
- **Pull from GitHub and Amazon ECR,** signing in through each registry's own page.
- **Select and copy a container's logs.**
- **A USB device that drops off and comes back is attached again.** Devices Kiri waits for show as waiting, in the window and in `kiri usb ls`, and Stop waiting lets them go.

## Fixed and improved
- **Start and Stop no longer race.** Stopping Kiri right after starting it stops every container, and Stop with many containers takes seconds, not a minute or more.
- **`unless-stopped` and `always` containers come back** after Kiri is stopped and started again.
- **A command that can't run exits as on Docker:** 126, 127 or 255, with Docker's message.
- **Mac: `/etc` paths work in bind mounts, and a linked folder follows its link,** also after you point the link somewhere else and restart.
- **Disconnecting a container from its networks works in any order,** and the network can be removed after.
- **A stop wins over a pending restart,** and Docker hears a container is stopped only once it really is.
- **The Linux VM card shows the engine's real state** and fits the sidebar in every language.
- **A language picked in Settings changes the whole window at once.**
- **"Port already allocated" names the program that has the port.**
- **Linux: stopping the engine removes its bridges and firewall rules.**
- **The terminal keeps the size you give it,** and `kiri` on the PATH finds the VM's kernel.
- **Kiri in 38 languages,** with Arabic, its first right-to-left language, and Amharic, its first Ethiopian one. Pick yours from a short, searchable list, on first start or in Settings › Appearance.
