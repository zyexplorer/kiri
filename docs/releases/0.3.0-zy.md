## Personal 0.3.0-zy (Windows)

Fork build from `zyexplorer/kiri` (`personal`). Update feed points at this repository's GitHub Releases.

### New
- **Reclaim Linux disk space** from Settings → Resources (compact the WSL VHDX after deleting images).
- **Online updates for this fork**: checks `zyexplorer/kiri` Releases instead of the official CDN.

### Fixed
- **Run** honors container name, host port, and custom `docker run` fields on Windows.
- **Switch to Kiri** banner no longer false-triggers from docker context status.
- **daemon.json** mirror editor keeps scroll position while Settings refreshes.
- Portable pack script stops a locked `kiri-win.exe` before rebuilding.

### Notes
- Install this MSI first; later `0.3.x-zy` builds upgrade in-app like upstream Windows.
- Each release must bump the numeric version (`0.3.1-zy`, …), not only the `-zy` suffix.
